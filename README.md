# SalesPulse Analytics

A responsive retail sales analysis dashboard portfolio project. The demo includes interactive KPI cards, revenue and product charts, transaction filters and sorting, CSV export, a workflow overview, and Python, SQL, and interview examples.

## Run locally

Open `index.html` in a browser. The dashboard is a static site and does not require a build step or package installation.

## Publish with GitHub Pages

Push this repository to the `main` branch. The workflow in `.github/workflows/deploy-pages.yml` deploys the site automatically. In the repository settings, set **Pages → Build and deployment → Source** to **GitHub Actions**. The published URL appears in the workflow run and Pages settings.

## Project files

- `index.html` — page structure and dashboard sections
- `style.css` — responsive visual design
- `app.js` — demo data, charts, filters, sorting, and export behavior
